# AI-Powered P2P EV Charger Sharing & Smart Route Planner (Frontend)

Modern, responsive React frontend prototype for:

- Route planning with battery-aware trip inputs
- Map-centric charger discovery and recommendation
- Charger details, booking flow, and owner charger listing

## Run locally

1. Install dependencies:
   - `npm install`
2. Start dev server:
   - `npm run dev`
3. Open:
   - `http://localhost:5173`

## Stack

- React + TypeScript + Vite
- React Router
- Zustand
- TanStack React Query
- React Hook Form + Zod
- Leaflet + React Leaflet
